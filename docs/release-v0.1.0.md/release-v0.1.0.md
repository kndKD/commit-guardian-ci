# Release v0.1.0 — Project 1

First tagged release of the Project 1 Flask app.

## What is in it

- Flask app with `/`, `/health`, `/api/hello`, `/api/status` and
  `/api/echo` endpoints, and JSON error responses for 404, 405 and 400.
- AI Commit Guardian (`guardian/`): rule-based Conventional Commits
  checker (score 0–100) with an optional LLM suggestion layer
  (Ollama / OpenAI / Gemini, disabled by default, no keys in the repo).
- GitHub Actions CI: build-and-test, ruff lint, hadolint for the
  Dockerfile, PR commit review with a per-commit score table, and
  auto-generated changelog on merge to `main`.
- Multi-stage Dockerfile (builder + slim runtime, non-root user),
  Makefile and helper scripts, 23 pytest tests, 77% coverage
  (reported, not gated).

## Known limits

- Docker builds are verified in CI only — Docker is not installed on
  the author's local VM, so no local image size is claimed.
- `guardian/llm.py` coverage is 26%: the LLM providers are disabled
  by default and their paths need mocked tests before any coverage gate.
- The changelog on `main` is regenerated by the CI bot after every
  merge; the file at a tag is a snapshot of that moment.

## How to run it

```sh
python -m venv .venv && source .venv/bin/activate
pip install -r requirements-dev.txt
python -m pytest -q
python app/main.py
# or: docker build -t commit-guardian-ci:latest . && docker run -p 5000:5000 commit-guardian-ci:latest
```
